Common questions

Before your first lecture

Is this made by Zoom?

No. Zoom Recorder is an independent open-source project and is not affiliated with or endorsed by Zoom Video Communications, Inc.

Does it upload my recording?

No. Recordings and transcripts stay in your local Windows application-data folders.

Why does Windows show a warning?

The current personal release is not commercially code-signed. The Download page explains how to verify the file before opening it.

Does transcription need internet?

Only for the first verified English Whisper model download, approximately 500 MB. Later transcriptions can run offline.
