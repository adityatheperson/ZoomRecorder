Before you begin

  • Windows 10 version 2004 (build 19041) or newer
  • 64-bit Windows PC
  • Zoom Workplace installed for your Windows user
  • Internet access for the first local transcription-model download

Install in four steps

  1. Download the ZIP from the official release.
  2. Extract the entire ZIP to a folder you control. Do not run the application from inside the ZIP.
  3. Open the extracted folder and run ZoomRecorder.App.exe.
  4. If Windows displays a warning, select More info, confirm the publisher is unknown, and proceed only after verifying the checksum.

Verify the download
