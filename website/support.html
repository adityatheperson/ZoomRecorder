Help & troubleshooting

Get back to class.

Start with the common fixes below. If the problem continues, open a GitHub issue with enough detail to reproduce it.

Common fixes

Zoom window not found

Install Zoom Workplace for your current Windows user, sign in if required by the meeting, and keep the meeting window open.

Recording will not start

Check Windows microphone permissions, confirm another app is not exclusively using the device, then restart Zoom Recorder.

Transcription cannot start

Confirm you have internet for the first model download and enough free disk space. Retry after the download completes.

Transcription uses the CPU

This is expected when Vulkan GPU initialization is unavailable. Processing can continue with the clearly indicated CPU fallback.

Report a problem

GitHub Issues is the public support channel. Before posting, remove meeting links, names, transcripts, credentials, and other private information.

Include the app version, Windows version, what you expected, what happened, the exact error message, and simple reproduction steps.

Current limitations

  • Windows x64 only
  • Zoom Workplace must be installed
  • Local transcription is English-only
  • Summaries and generated study materials are not currently available
